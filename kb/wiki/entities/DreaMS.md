# DreaMS

A project that released **pretrained spectrum-embedding models** plus **GeMS**, a large curated corpus of unannotated spectra mined from MassIVE (repository-scale self-supervised pretraining). The official description lists it as a shortcut to pretraining; the repo's stage-3 plan names DreaMS embeddings as the comparison baseline for a learned cross-setting Siamese embedding ([[concepts/solution/Roadmap]]). Pretrained and public → usable in the offline kernel as an attached dataset ([[concepts/solution/Submission Architecture]]).
