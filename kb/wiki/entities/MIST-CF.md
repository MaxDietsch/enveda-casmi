# MIST-CF

A machine-learned model for **molecular-formula prediction** from tandem-mass spectra (contrast with rule-based tools). Named in the official data description alongside [[entities/SIRIUS|SIRIUS]] as the reference method for the formula-first strategy: predicting the formula first and conditioning on it is a common way to narrow the structure search space before ranking candidates ([[concepts/solution/De Novo Channel]]).
