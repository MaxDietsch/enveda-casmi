# matchms

Open-source Python library for mass-spectrometry work: spectrum I/O, cleaning/curation, and similarity functions (including entropy similarity, which the repo re-implements vectorised in `max_class1_exp/spectra.py`). Listed in the official data description as a standard resource. The repo implements its own one-against-many similarity kernels for speed ([[concepts/solution/Retrieval]]).
