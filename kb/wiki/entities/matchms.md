# matchms

An open-source Python library for mass-spectrometry work: reading spectra, cleaning and curating them, and computing similarity measures (including entropy similarity — which the repo re-implements in vectorised form in `max_class1_exp/spectra.py` for speed). Listed in the official data description as a standard resource ([[concepts/solution/Retrieval]]).
